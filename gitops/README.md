# Publishing House — GitOps (ArgoCD, app-of-apps)

Declarative deployment of Publishing House, captured **from the live cluster as-is**.
Cluster/deploy values are **not** hardcoded in the chart — they are passed by the
ArgoCD Application via `spec.source.helm.parameters`.

## Layout

```
gitops/
├── argocd/
│   ├── app-of-apps.yaml                  # ROOT Application → deploys children in apps/
│   └── apps/
│       ├── 01-operators.yaml             # child: operators + namespaces   (sync-wave 0)
│       └── 02-publishing-house-infra01.yaml  # child: Helm chart + params  (sync-wave 1)
├── operators/                            # plain manifests: Subscriptions + OperatorGroup + namespaces
├── chart/                                # the Helm chart (all workloads/CRs/config/secrets)
│   ├── Chart.yaml
│   ├── values.yaml                       # EMPTY placeholders only (no hardcoded values)
│   ├── files/                            # raw embedded content (plugins, job scripts)
│   └── templates/                        # 10-secrets … 70-jobs
└── export.py                            # regenerate chart/templates from a live cluster
```

## App-of-apps flow

1. Apply the **root** (`app-of-apps.yaml`). It watches `gitops/argocd/apps/`.
2. Child **01-operators** (wave 0) installs the rhbk/rhdh/devspaces Subscriptions,
   the keycloak OperatorGroup, and the namespaces — so CRDs exist first.
3. Child **02-publishing-house-infra01** (wave 1) deploys the Helm chart, passing all
   values as `helm.parameters`. Sync-waves inside the chart order the rest
   (secrets → data → keycloak → sonataflow platform → central-api → workflow → rhdh/devspaces → jobs).

## Values are passed by the Application (not hardcoded)

`chart/values.yaml` is intentionally empty. Each per-cluster Application sets them:

```yaml
# gitops/argocd/apps/02-publishing-house-infra01.yaml
spec:
  source:
    helm:
      parameters:
        - { name: appsDomain,                 value: apps.ocpv-infra01.dal12.infra.demo.redhat.com }
        - { name: centralApi.image,           value: quay.io/rhpds/central-api }
        - { name: centralApi.tag,             value: "2.0.0" }
        - { name: sonataflow.profile,         value: preview }   # gitops for infra02
        - { name: sonataflow.workflowImage,   value: image-registry.openshift-image-registry.svc:5000/publishing-house/rhdp-published:latest }
        - { name: rhdhPlugins.phWorkflows,    value: "2.0.0" }
        - { name: rhdhPlugins.scaffolderModule, value: "1.1.5" }
        - { name: rhdhPlugins.readme,         value: "0.1.0" }
        - { name: rhdhPlugins.readmeBackend,  value: "0.1.0" }
```

To deploy to a different cluster/mode, copy the child Application and change the
parameters (e.g. infra02: `appsDomain`, `sonataflow.profile=gitops`,
`sonataflow.workflowImage=quay.io/rhpds/rhdp-published:<tag>`).

## Parameters

| Parameter | Purpose |
|---|---|
| `appsDomain` | cluster apps domain — drives all routes/OIDC/CORS/redirect URIs |
| `centralApi.image` / `centralApi.tag` | central-api image (bump tag to upgrade) |
| `sonataflow.profile` | `preview` (build in-cluster) / `gitops` (pre-built image) |
| `sonataflow.workflowImage` | workflow runtime image |
| `rhdhPlugins.*` | custom RHDH plugin versions (upgrade = bump) |
| `keycloak.*` | 3 client/IdP secrets — **injected at deploy, never committed** |

## Secrets

- `publishing-house-credentials` + `github-oauth-config` are generated by **ExternalSecrets** from Vault — nothing to supply.
- 4 static secrets (keycloak-db, sonataflow-svcbind, ph-developer-hub-env, console-oauth) are **redacted** in the chart.
- 3 Keycloak client secrets (`keycloak.rhdhClientSecret`, `portalClientSecret`, `corporateSsoClientSecret`) are empty by default.
- Supply all of the above at deploy time (sealed values / vault plugin / `oc patch application`), never in git. The `rhdhClientSecret` is auto-wired into `ph-developer-hub-env`.

## Prerequisites (not managed here)

- **openshift-gitops** (ArgoCD), **External Secrets Operator**, **logic-operator** (Serverless Logic) installed.
- **Vault** deployed, unsealed, and **seeded**.

## Deploy

```bash
# ArgoCD reads from git — commit & push gitops/ to the branch referenced by
# targetRevision in the Application manifests first.
oc apply -f gitops/argocd/app-of-apps.yaml
```
Automated sync is on with `prune:false` + `selfHeal:false` (safe first run). Flip to
`true` once validated.

## Not included (deliberately)

- **Operator-reconciled children** (backstage/data-index/jobs Deployments, props/build CMs) — recreated by their CRs.
- **Dead resources**: `central-api-postgresql` svc + `central-api-db` secret, `workflow-proxy` svc/cm.

## Regenerate chart templates from a live cluster

```bash
oc login <cluster> && cd gitops && python3 export.py   # writes raw manifests; re-apply parameterization after
```
